# IPT & GPTC Shoranur website

College website project with Express, MongoDB, and Handlebars, including department pages, galleries, and an admin content interface.

## Configuration

Connected features require MongoDB, an SMTP/email configuration. Review the corresponding configuration and integration modules before running the app.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run start
```
